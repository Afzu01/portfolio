# Portfolio Website (GitHub Pages)

This is a free static portfolio site that showcases six AI/backend projects.

## Local preview

Open `index.html` directly in your browser, or use any static server.

## Publish for free with GitHub Pages

1. Create a new repository named `afzu01.github.io` (or any repo name).
2. Push these files to that repository.
3. In GitHub: `Settings` -> `Pages`.
4. Under `Build and deployment`, choose:
   - Source: `Deploy from a branch`
   - Branch: `main` and `/root`
5. Save and wait 1-2 minutes.
6. Your site will be live on:
   - `https://afzu01.github.io` (if repo is `afzu01.github.io`)
   - or `https://afzu01.github.io/<repo-name>/`

## Notes

- This uses only HTML/CSS/JS, so hosting stays free.
- Update project links in `script.js` if repository names change.
